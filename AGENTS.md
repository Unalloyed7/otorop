# Работа в репозитории

- Сообщения коммитов — простые, короткие, на русском языке.
- Сохраняйте изменения других участников; перед коммитом и отправкой проверяйте git status и актуальную удалённую ветку. Не используйте force-push.
- Зоны участников и подключения описаны в PLAN.md и docs/contracts.md. Изменение общего контракта требует обновления примеров и адаптеров.
- Веб и solution.py используют один движок. Runtime-модули должны оставаться в корне для переноса платформой.
- Не включайте ключи, .env, закрытые ответы и подстановки ответов по ID. Демоответы не являются рабочей базой.
- Перед отправкой выполняйте `.venv/bin/python -m pytest -q` и `git diff --check`. Тесты с заглушками не выдавайте за проверку качества реальной модели.
