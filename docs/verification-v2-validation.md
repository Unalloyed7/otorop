Сырой вопрос №5 содержит историческую дату. Аудит поиска без Intent не передаёт её фильтром и не находит нужную историческую редакцию. Это ограничение данного режима аудита, не измерение извлечения даты моделью. Открытые примеры — регрессия, не независимая оценка.

## Новые регрессии

- Проверка субъекта, чисел, единицы срока, календарных/рабочих дней и точных ссылок каждого утверждения. Подтверждённые части сохраняются независимо от отброшенных.
- Общее правило → исключение для типовой формы → допсоглашение → условный вывод. Противоречивый общий вывод доступен для исследования, но не включается в проверенный ответ.
- Четыре независимые даты, русские месяцы и годы, диапазоны. Месяц не подменяется первым числом; изменение правила внутри интервала требует уточнения. Равное правило двух редакций требует обеих цитат.
- Одна общая попытка исправления схемы вместо объекта, неизвестного поля, неправильного индекса или ссылки. Юридические проверки сохраняются.
- Проверенная часть остаётся в partial при ошибке исправления, исчерпании бюджета и общем тайм-ауте дополнительной проверки. Пробел обозначается явно.
- Повторный поиск не вытесняет исходное основание из-за несопоставимых BM25-оценок разных запросов. Комплект положения не обрезается незаметно, нехватка контекста отмечается.
- Общий бюджет поиска и моделей, включая необязательные генеративные вызовы конвейера №1. История и попытка исправления изолированы между параллельными вопросами.
- Идемпотентные задания, 409 при другом содержимом с тем же ключом, отмена без разрушения очереди, восстановление после перезагрузки браузера. Сессия создаётся при открытии страницы до первого POST.
- Изоляция заданий, запусков и оценок, инертный HTML документов/запросов/импорта, ручные оценки отдельно от официальных баллов.

## Повторение

```bash
.venv/bin/python -m pytest -q
.venv/bin/python tools/browser_smoke.py
.venv/bin/python tools/audit_retrieval.py --bundle --output dist/retrieval-v2.json
.venv/bin/python tools/package_submission.py --output dist/psb-submission-v2.zip --with-report --verify-answer 1
git diff --check
```

Браузерная проверка требует Playwright и Chrome; для установленного Chromium передайте `--channel chromium`. Она использует временную вымышленную базу и HTTP-заглушку вне рабочего контекста. JSON-отчёт и снимки — в dist/browser-check. ## Ограничения

Настоящие вызовы DeepSeek и сравнение качества новой схемы с прежней не выполнены: официальный прокси выдаётся только на платформе, собственного доступа у команды нет. JSON-режим не предполагается; обычный текстовый ответ проверяется Pydantic. Заглушки не доказывают качество модели и не предсказывают балл.

Смысловая проверка способна ошибаться. Граф связей включает кандидатов и не доказывает юридическую истинность связи. Ограниченный поиск не гарантирует всех исключений. Неизвестные условия остаются неизвестными, исторические редакции не достраиваются по памяти.

Веб рассчитан на один процесс uvicorn и браузерные сессии, корпоративных учётных записей нет. Готовые задания переживают перезапуск; прерванный модельный вызов становится ошибкой без автоматического повтора. Координаты и просмотр относятся к извлечённому тексту, не к визуальному PDF/DOCX.
