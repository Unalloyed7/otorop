# Живая проверка Gemini — 12.11.2026

Пользователь разрешил передать Google Gemini три вопроса и найденные фрагменты
базы хакатона. Проверка использовала `gemini-3.1-flash-lite`, штатные LLMClient,
LegalAssistant и retrieval:create_search; VERIFY_ANSWER=1, MAX_WORKERS=1,
MAX_TOKENS=4096, TOP_K=12. Embeddings, reranker, LLM-извлечение и проверка
графа выключены. Это проверка генерации поверх BM25/графа, а не замена
конкурсного DeepSeek и не измерение качества bge-m3/reranker.

У модели есть Free Tier с квотами:
[официальные тарифы](https://aistudio.google.com/docs/pricing#gemini-3.1-flash-lite).
Ключи и локальные .env/.env.gemini исключены из Git и ZIP.
Параметры конкурсной модели по-прежнему поступают из окружения платформы.

## Обнаруженная ошибка

Первоначальный сквозной запрос нашёл п. 4.2 договора и сформировал ответ
с корректной цитатой. Проверяющая модель вернула `supported=[4]` при одном
проверяемом выводе. Индекс вне диапазона был корректно отклонён, но весь ответ
получил технический статус `error`. Причина выбора моделью числа 4 не установлена.

В запрос самопроверки добавлены явные `claim_index` и `allowed_claim_indices`.
Промпт отличает их от индексов подвопросов, номеров источников и пунктов.
Допуск неверных индексов не расширен, автоматическое исправление номера
не выполняется. Существующий регрессионный тест проверяет нумерацию после
отбрасывания первого невалидного вывода; тест некорректного Verdict сохранён.
Полный локальный набор после изменения: 277 passed.

№19: ответ содержит 30 календарных дней от подписания УПД и цитату п. 4.2.
№20: ответ сохраняет подтверждённые 30 дней, не подставляет 90, но перегружен
техническими пробелами графа и лишними оговорками; полным качественным ответом
его не считаем. №60: запрошено уточнение контрагента/договора вместо выбора
одной из похожих организаций. Это ручная проверка трёх конкретных результатов.

Исходные ответы и диагностика сохранены локально в игнорируемом
`reports/gemini-smoke-20261112-123032.jsonl`; первые неуспешные прогоны тоже
сохранены. Эти три вопроса использовались для настройки: это не независимая
оценка. Все 72 сценария через настоящую модель не прогонялись; офлайн результаты
71/72 и 63/71 из recovery-validation.md остаются отдельной проверкой поиска.

Локальный Docker Compose читает `.env`. Для прямого запуска Python переменные
нужно экспортировать; `.env` автоматически не загружается:

```bash
set -a
source .env.gemini
set +a
```

Первоначально выбранная gemini-3.8-flash возвращала 503/тайм-ауты, а
gemini-2.5-flash вернула явный 404 о недоступности для новых пользователей.
Список моделей сам по себе не подтвердил возможность генерации; Flash-Lite
проверена коротким структурированным запросом и указанными полными запросами.
