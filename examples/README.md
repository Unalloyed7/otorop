# Примеры контракта v1

Все данные здесь вымышлены. Их нельзя использовать как базу знаний или готовые конкурсные ответы. Рабочий движок читает только переданную базу и подключённый поисковый backend.

- evidence.json — точный фрагмент и координаты.
- search_filters.json — номер, контрагент и дата с явным смыслом.
- search_result.json — выдача поиска.
- answer.json — ответ с точным основанием и claim_index.
- schemas.json — JSON Schema публичных моделей Pydantic.

Формат и правила подключения: ../docs/contracts.md.
